# User Guide

KaGet helps you budget by **allocating money into envelopes** before you spend — like moving cash from a wallet into labeled pockets.

You do **not** need an account to use KaGet. Your ledger lives on this device. Optionally, connect **Google Drive** in Settings to keep a backup file you own (see [Import & Export](./settings/import-export.md)).

## Getting Started

- [Onboarding](./onboarding/) — Set up currency and learn the basics

## Features

- [Wallets](./wallets/) — Cash, bank, and e-wallet accounts
- [Records](./records/) — Income and expenses
- [Budgets](./budgets/) — Spending envelopes and saving goals
- [Transfers](./transfers/) — Move money between wallets and budgets
- [Debts & Loans](./debts-loans/) — Money you borrowed or lent
- [Settings](./settings/) — Currency, import/export, Drive sync
